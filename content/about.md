This is a home for essays, notes, and other things worth putting into words. The layout stays quiet so the writing can take up space.

The site is built with [Zola](https://www.getzola.org/), plain Markdown, and a small amount of CSS and JavaScript. It has no tracking, advertisements, or remote font requests. You can follow new writing through the [Atom feed]({{ get_url(path='atom.xml') }}).
